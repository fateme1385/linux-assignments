# linux-assignment

## تکلیف اول

### ۱. نمایش مسیر فعلی

```bash
pwd
```

خروجی:

```
/home/ubuntu
```

### ۲. رفتن به دایرکتوری etc و بررسی مسیر

```bash
cd /etc
pwd
```

خروجی:

```
/etc
```

### ۳. نمایش لیست کامل فایل‌ها (شامل فایل‌های مخفی)

```bash
ls -la
```

بخشی از خروجی:

```
total 404
drwxr-xr-x  1 root                 root                   680 Nov  1 11:00 .
drwxr-xr-x  1 root                 root                   260 Nov  1 10:45 ..
...
```

### ۴. بازگشت به دایرکتوری home

```bash
cd ~
pwd
```

خروجی:

```
/home/ubuntu
```
