### ۱. جستجوی پیشرفته: مرتب‌سازی فایل‌ها بر اساس حجم

با دستور `man ls` و جستجوی کلمه `sort` در صفحه راهنما، سویچ زیر پیدا شد:

```
-S     Sort by file size, largest first.
```

یعنی سویچ `-S` فایل‌ها را بر اساس حجم و از بزرگ به کوچک مرتب می‌کند.

```bash
man ls
cd /etc
ls -lS
```

### ۲. تحقیق معماری: تفاوت بین دایرکتوری‌های bin و sbin

**`/bin`** (مخفف binaries) شامل برنامه‌ها و دستورهای پایه‌ای سیستم است که **همه کاربران** می‌توانند استفاده کنند و برای کار روزمره و بالا آمدن سیستم ضروری‌اند. مثال‌ها: `ls`، `cp`، `mv`، `cat`، `mkdir`.

**`/sbin`** (مخفف system binaries) شامل دستورهای **مدیریت و نگهداری سیستم** است که معمولاً فقط **کاربر root** (یا کاربری با `sudo`) به آن‌ها نیاز دارد و اجرا می‌کند. مثال‌ها: `reboot`، `fdisk`، `ip`، `mkfs`، `shutdown`.

| ویژگی | `/bin` | `/sbin` |
|---|---|---|
| نوع دستورها | دستورهای عمومی و پایه | دستورهای مدیریتی سیستم |
| کاربر اصلی | همه کاربران | root / مدیر سیستم |
| مثال | `ls`, `cp`, `cat` | `reboot`, `fdisk`, `ip` |

برای دیدن محتوای این دو دایرکتوری:

```bash
ls /bin
ls /sbin
```

**نکته:** در نسخه‌های جدید اوبونتو، `/bin` و `/sbin` در عمل لینک نمادین (symbolic link) به `/usr/bin` و `/usr/sbin` هستند. این را با دستور زیر می‌توان دید:

```bash
ls -ld /bin /sbin
```

### ۳. ترسیم نقشه: نمودار درختی رابطه والد و فرزندی

دایرکتوری ریشه (`/`) والد همه دایرکتوری‌های دیگر است و هر کدام از چهار دایرکتوری زیر، فرزند مستقیم آن هستند:

```
/
├── etc
├── home
├── bin
└── usr
```

برای نشان دادن رابطه عمیق‌تر (والد و فرزند در چند سطح)، می‌توان زیرپوشه‌ها را هم نشان داد:

```
/
├── etc
├── home
│   └── ubuntu
├── bin
└── usr
    ├── bin
    └── sbin
```

در این نمودار:

- `/` والد همه است (ریشه).
- `/home` والد `/home/ubuntu` است.
- `/usr` والد `/usr/bin` و `/usr/sbin` است.)
